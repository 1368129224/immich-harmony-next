# 功能与 UI 设计简案

> 给人阅读的产品概览：我们要做什么、页面如何组织、关键操作怎样工作。
> 本文描述设计目标，不代表所有功能均已完成。开发细节与已知差距见 [Agent 详细设计规范](AGENT_DESIGN_SPEC.md)；协作和验证规则见 [开发行为规范](DEVELOPMENT_RULES.md)。

## 1. 产品定位

一个连接自建 Immich 服务器的原生相册客户端，将手机照片和当前账户的云端照片放在一起浏览、整理与备份。

- 面向 iOS、HarmonyOS NEXT，Android 为后续规划；三端功能语义统一，操作遵循各自系统习惯。
- 使用自己的 UI，不复制 Immich 官方客户端源码。
- 照片是主角：界面克制、滚动稳定、状态清楚；删除、共享和上传都让用户知道影响范围。

## 2. 四个页面

| 页面 | 主要内容与设计 |
| --- | --- |
| **照片** | 手机与云端合并照片流；显示备份状态，支持缩放、多选和打开大图 |
| **相册** | 手机与云端相册混合展示，同名合并成一个入口；支持名称排序和置顶 |
| **搜索** | 搜索照片、人物、地点与条件筛选；明确搜索范围，具体首屏布局后续细化 |
| **资源库** | 人物、回收站、收藏、归档等分类与管理入口，不重复展示所有照片 |

当前 iOS 底栏从左到右为 **照片 · 相册 · 搜索 · 资源库**。

资源库目前按以下分组呈现：

```text
资源库
├─ 常用管理：人物、回收站、收藏、归档
├─ 集合与分类：地点、本机照片、回忆
├─ 共享与访问：共享链接、伙伴共享、标签
├─ 相册与设置：合并相册偏好、照片页设置、检查更新
└─ 调试与版本信息
```

人物展示服务器已识别的人物；回收站用于访问云端已移除内容。

## 3. 照片浏览体验

- **最新在底部**：按拍摄时间排列，打开时看最新照片，向上翻看过去。
- **正方形网格**：默认四列，双指缩放可在二至十五列之间调整密度。
- **状态可辨认**：右下角图标区分本机、云端及备份状态；匹配可靠的同一照片只显示一次。
- **位置稳定**：切 Tab、开大图返回、进入或退出多选都不应突然跳位；浏览旧照片时新增内容只提醒。
- **回到最新**：提供明确入口；iOS 单击当前照片 Tab 不跳动，双击平滑回到最下方。
- **连续多选**：长按起点，横向或斜向选择起终点之间的一段照片；竖向起手仍用于滚动，多选时固定列数。当前部分网格实现仍需对齐这一目标。

## 4. 大图查看器

- 打开查看器时，界面UI参考iOS原生相册。
- 手势、全屏显示、按钮显示隐藏，都参考iOS原生相册的逻辑。
- 每次打开显示工具栏，单击照片切换显隐，左右切图保持显隐状态。
- 支持缩放、左右浏览、详情、收藏、加入相册、分享和按状态删除；返回时回到原照片附近。
- 下拉关闭不能和横向翻页打架，不出现半页露出。
- 进入查看器后视频开始播放，显示进度条。
- 实况照片长按播放，并提供可见入口；缺少动态资源时如实提示。
- 提示面板与按钮遵循 iOS 等平台的原生风格，同时适配深浅色、大字号和读屏。

### 删除分三种情况

| 照片在哪里 | 显示什么 | 点击后 |
| --- | --- | --- |
| 只有云端 | **回收站** | 提醒移入云端回收站，可勾选“不再提醒” |
| 本机和云端都有 | **删除** | 选择“仅删除本地”或“全部删除” |
| 只有本机、尚未同步 | **删除** | 提醒未同步，确认仅删除本机照片 |

仅删本地必须保留云端照片。系统图库删除可能影响 iCloud 同步；云端回收站是否可恢复由服务器配置决定，不保证固定保留天数。

## 5. 相册整理

- 默认两列，设计目标支持二至四列缩放；相册内按拍摄时间排列，默认进入底部看最新。
- 同名手机 / 云端相册合并展示，但不自动上传、不补齐成员、不联动删除。
- 按名称字母 / 拼音排序，常用相册可置顶。
- 点击进入，长按进入多选、点击勾选；正常浏览和多选时都应能上下滑动。
- 删除相册、移出照片和删除照片是不同操作，需明确区分。

## 6. 备份、保存与分享

### 自动备份

首发目标包含自动备份。用户先选择手机相册，再主动开启；默认仅 Wi-Fi、不要求充电。显示上传、失败、等待网络或系统调度等真实状态，不承诺退出或锁屏后立即完成。

只备份当前浏览账户。切换账户时暂停旧账户任务，新账户使用自己的设置，不把任务改投其他账户。

### 保存与缓存

“存到相册”应把原图保存到系统图库，不只放在 App 缓存中。清缓存只能删除可重建的 App 文件，不能删除手机照片、云端原件、登录信息或业务记录。

### 分享

设计目标是先选 **原件 / 兼容副本 / 云端链接**，分享时询问是否去掉 GPS。只处理分享副本，不修改原件；实况尽量保持实况，不支持时明确说明，由用户选择替代方式。

云端链接不隐式上传手机照片。共享相册、公开链接和伙伴共享是目标范围，完整管理功能仍需逐项完成。

## 7. 账户与数据安全

- 支持多个服务器和账户，登录页保存使用历史；数据库、缓存和后台任务按账户隔离。
- 目标登录方式为密码、OAuth、API Key；OAuth 等能力仍需完善与验证。
- 云端浏览不强制申请手机图库权限，部分授权不等于手机没有照片。
- 收藏先保存 App 意图，系统允许时联动；正常上传并匹配后同步当前账户云端收藏，不因点收藏偷偷上传。
- 曾同步后云端被删除但手机仍有原件时，继续显示并标明状态，不自动重新上传；只有明确手动上传才解除本次上传限制。

## 8. 当前重点

iOS 已有原生工程及照片、相册、资源库、备份等实现路径；HarmonyOS 已有工程与桥接；Android 仍为规划。

接下来应优先验证和补齐：真实设备上的滚动与连续多选、删除语义和回收站管理、账户隔离与后台备份、OAuth、最近添加、完整共享及实况分享。**有入口、有代码与真机可用分别验收，不把目标清单当成功能完成清单。**
